# db_backup
## バックアップの実行
### 概要
データベースに登録されている直近7日分のデータをバックアップする。  
毎日0時に当日分のデータをバックアップし、7日前のデータを削除する。

### 操作手順
以下のコマンドを実行し、バックアップの定期実行を登録する。
```
crontab cron_mongo_backup
```

バックアップ対象のデータベース情報は`execute_backup.sh`で設定する。
- ホスト名
- ポート番号
- データベース名（デフォルト値：log）

## データの復元  
### 概要
指定した日付のデータをバックアップファイルからデータベースに復元する。

### 操作手順
以下のコマンドを実行する。
```
./restore_db.sh ※日付※
```
- 日付：データを復元する日付（yyyymmdd）。（例：20260101）

復元先のデータベース情報は`restore_db.sh`で設定する。  
- ホスト名
- ポート番号
- データベース名（デフォルト値：ReadOnlyLog）
