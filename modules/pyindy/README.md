# pyindy

## 現在の最新コードはdevelopブランチにあります。

## インストール方法
以下のコマンドによって、pyindyのdevelopブランチの内容をインストールできます。
- (HTTPS方式の場合)
  ```
  pip3 install --upgrade --force-reinstall git+https://github.com/riken-grp/pyindy.git@develop
  ```
- (SSH方式の場合)
  ```
  pip3 install --upgrade --force-reinstall git+ssh://git@github.com/riken-grp/pyindy.git@develop
  ```
- 他のブランチを指定する場合は末尾に"@ブランチ名"を付ける。
  ```
  pip3 install git+https://github.com/riken-grp/pyindy.git@ブランチ名
  ```
